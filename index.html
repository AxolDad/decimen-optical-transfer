DECIMEN — Fountain QR File Transfer (PoC)

YouTube as a dead drop. Encrypt a file, post it anywhere as a stream of animated light, and only the key holder can ever open it — no network, no account, no trace of what it is.

Send a file between two devices using nothing but a screen and a camera. Open send on the device with the file (a laptop is ideal) and receive on a phone, then point the phone's camera at the flickering code.

No network path between the devices is used — the payload travels as light. Fountain coding means the receiver can drop any frames, in any order, and still reconstruct the file.

Tuning? The bench page runs the whole pipeline camera-free to measure this device's decode ceiling. Curious? The kaleidoscope experiment draws the same fountain stream as a spinning mandala of colored wedges instead of QR codes.
