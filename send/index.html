Settings
Changing anything restarts the stream, and the receiver resets itself off the new session id. That's the fountain protocol's gift. Frames are held for a whole number of display refresh cycles, so the actual fps shown above is the nearest exact division of your screen's refresh rate. Grids multiply data per frame but shrink the modules: get closer, or use a bigger display.

Encrypt for YouTube

Seals the file and records a transcode-hardened clip: big modules, a slow code rate so each code spans several video frames, high error correction and heavy fountain redundancy, rendered at 4K. The codec's damage then lands on frames the fountain can spare rather than on your file. Upload it, keep the key, and only the key opens it.

Measured against simulated AV1, VP9 and H.264 ladders: byte-exact down to 240p, breaking at 144p, so download at 480p or better and keep two rungs of margin. That simulates the codecs YouTube delivers; it is not a YouTube round-trip. Treat it as a durable second copy, not your only one.

While it runs

Maximum screen brightness helps. The stream loops forever; stop when the receiver says it's done. Drop any file anywhere on this page to send it: name and type travel inside the stream, and compressible files are deflated on the fly. Sealed streams are ciphertext end to end, so an exported clip can be hosted anywhere and only the key opens it.
